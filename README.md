# Angular-Spring Web Application

## Overview
A web application built with Angular for the frontend, Spring Boot for the backend, and MongoDB as the database. 

## Technologies
- **Frontend**: Angular 17
- **Backend**: Spring Boot 3
- **Database**: MongoDB

## Setup Instructions
### Prerequisites
- **Node.js**: Version 18 or higher (for Angular).
- **Java**: JDK 17 or higher (for Spring Boot).
- **MongoDB**: Version 4.4 or higher, installed and running locally or via a cloud service.
- **Git**: To clone the repository.
- **Maven**: For building the Spring Boot backend (or use the Maven Wrapper included).
